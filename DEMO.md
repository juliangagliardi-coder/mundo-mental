# Demostración integrada

Ejecuta el ciclo completo con:

```bash
python iniciar.py
```

La demostración usa un directorio temporal y no modifica `.mente/`. El orden es deliberado:

1. Curiosidad detecta un vacío y muestra su primera pregunta.
2. Ejecuta un experimento aislado y comprueba si es reproducible.
3. Un validador independiente incorpora el resultado solo porque existe corroboración.
4. Observación recibe una alarma, congela temporalmente el laboratorio y registra el incidente.
5. El Guardián reanuda porque las cuatro señales obligatorias están presentes.

El flujo es un ejemplo controlado, no una afirmación de autonomía general. Si en una futura variante el experimento falla, el resultado deberá conservarse como fallido y la alarma deberá mantener el aislamiento hasta que las señales de reanudación se demuestren.
